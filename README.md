# BIG Partner Portal

The white-label distribution engine for telecom revenue.

Brokerage Interconnect Group (B.I.G.) is a master agent and telecom distribution platform enabling sub-agents, MSPs, IT consultants, and enterprise buyers to quote, track, and provision connectivity services through a centralized SaaS portal.

## Stack
- Next.js
- TypeScript
- Tailwind CSS
- Netlify-ready deployment

## Features
- White-label partner portal
- Telecom quoting engine
- Pipeline dashboard
- MRR tracking
- Carrier marketplace foundation
